# TrustIT Solutions - Landing Page

## 📌 Project Overview
This is a responsive landing page for a fictional IT company named **TrustIT Solutions**.  
The project is built as part of a frontend developer assessment task.

It includes modern UI design, responsive layout, and interactive features such as navigation menu, form validation, and smooth animations.

The goal of this project is to demonstrate practical frontend development skills including HTML structure, CSS styling, and JavaScript functionality.

---

## 🛠 Technologies Used

- HTML5
- CSS3 (Tailwind CSS via CDN)
- JavaScript (Vanilla JS)
- Google Fonts (Inter)
- SVG Icons

---

## ✨ Features

- Responsive design for mobile, tablet, and desktop
- Sticky navigation bar with mobile hamburger menu
- Hero section with background image and overlay
- Services section with icons and hover effects
- About section with image and content layout
- Contact form with JavaScript validation
- Smooth scroll navigation
- Dark-style modern UI design
- Social media icons in footer
